How it works

From your mic to a new voice, every quarter second.

  1. 01

    Microphone in

    Audio streams from the input device you choose, at 44.1 or 48 kHz.

  2. 02

    Clean-up rack

    A noise gate, high-pass filter and compressor remove room noise before the model hears it.

  3. 03

    Speech features

    HuBERT turns each chunk into content features, and FCPE or RMVPE tracks your pitch.

  4. 04

    RVC synthesis

    The voice model rebuilds the speech in the target timbre, guided by its FAISS index.

  5. 05

    Out to any device

    Converted audio goes to your speakers, a virtual cable for Discord or OBS, or both.

Features

Everything runs on your machine.

Your voice never leaves your computer. Models, conversion and effects all run locally, with no account and no subscription.

First launch on macOS

  1. Open the .dmg and drag RVC Voicechanger into Applications.
  2. The app isn't notarized by Apple yet, so the first open is blocked. Open System Settings → Privacy & Security and click Open Anyway.
  3. Allow microphone access when asked.

First launch on Windows

  1. Run the installer. If SmartScreen appears, click More info → Run anyway.
  2. Choose where to install, then launch from the Start menu.
  3. If no audio comes in, turn on microphone access in Settings → Privacy → Microphone.

Questions

Before you start talking.

How do I use my new voice in Discord, OBS or a game?

Install a virtual audio cable: BlackHole on macOS or VB-CABLE on Windows. In RVC Voicechanger, set the output device to the cable. In Discord, OBS or your game, pick the cable as the microphone.

Turn on Hear Myself and choose your headphones as the monitor device to hear the converted voice too.

What hardware do I need?

Conversion runs on the CPU. Apple Silicon Macs and recent desktop CPUs keep up at the default 256 ms chunk. On slower machines, raise the chunk size in Settings or use the DSP voice mode, which runs on anything.

The Windows release is CPU-only to keep the download small. If you run from source with a CUDA build of PyTorch, the app uses your NVIDIA GPU automatically.

Why does my computer warn me about the app?

The builds aren't signed with a paid Apple or Microsoft certificate yet, so macOS Gatekeeper and Windows SmartScreen warn you the first time. Every release is built by GitHub Actions from the public source, and SHA-256 checksums are attached to the release.

Where are my voice models stored?

In your user folder at ~/.aivoicechanger/models (on Windows, %USERPROFILE%\.aivoicechanger\models). They stay put when you update or reinstall the app.

Can I use voice models I downloaded elsewhere?

Yes. Click Import RVC Model and choose a .pth file, plus its .index if it has one. Models are opened in PyTorch's safe loading mode, so a model file can't run hidden code on your computer.

Is it really free?

Yes. RVC Voicechanger is open source under the MIT license. There is no account and no subscription.
